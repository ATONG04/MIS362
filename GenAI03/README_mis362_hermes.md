# MIS362 Hermes Workspace — `mis362_hermes`

## Purpose

This OneDrive folder stores approved MIS362 instructions, knowledge, simulated data, outputs, and testing evidence used by the Hermes profile named `mis362`.

## Profile and workspace distinction

### Hermes profile: `mis362`

Stores course-specific Hermes configuration, API keys, memory, sessions, skills, and tool settings on this Windows computer.

### OneDrive workspace: `mis362_hermes`

Stores course files that need to persist and synchronize.

## Required folders

- `01_Instructions` — approved rules and workflow instructions
- `02_Knowledge` — approved course knowledge and policy files
- `03_Data` — supplied simulated data
- `04_Outputs` — Hermes-created or student-created output files
- `05_Testing` — test cases, verification notes, and prior GenAI evidence

## Safety rules

- Never store API keys, passwords, private information, or real customer records here.
- Keep normal Hermes approval prompts enabled.
- Verify the active profile is `mis362` before using this workspace.
- Verify every proposed file path before approving a write.
- Do not allow Hermes to write outside `mis362_hermes`.
- Wait for OneDrive synchronization before closing or changing devices.
